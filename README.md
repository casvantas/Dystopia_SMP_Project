# Dystopia_SMP_Project
A dystopian SMP modpack for me and some friends to play, I do not own the rights to any of the mods included and create my own mods and datapacks for changes.

This is specifically for installation with Prism Launcher. I do not currently have plans for specifically creating packs for other launchers but if any are created in the future they will be explicitly labeled.

One mod I added specifically through the authors github repo directly and will give a warning when attempting to import to Prism. All credits goto the mod creator as well as the link to their mod page is https://github.com/SakurakoujiSaika1926/Reinhardt-s-HBM-NeoPort
